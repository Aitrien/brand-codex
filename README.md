# brand-codex

Single source of truth for design tokens and component guidance, shared by:

- **Hugo sites**: imported as a Hugo Module (`go.mod` + `hugo.toml`)
- **Other projects**: installed from npm or a git tag (`package.json`)
- **AI assistants**: through the MCP server in `mcp/` (Phase 3)

## Layout

```
tokens/              source of truth, DTCG JSON (Phase 1)
docs/components/     one markdown file per component (see _template.md)
dist/                generated by the build. Never edit by hand
mcp/                 MCP server (Phase 3)
scripts/             build and validation scripts
CONVENTIONS.md       token naming, versioning, file rules
```

## Commands

```sh
npm run validate   # checks every tokens/*.json parses and follows naming rules
```

## Using it from Hugo (from Phase 2)

```toml
# portfolio/hugo.toml
[module]
  [[module.imports]]
    path = "github.com/aitrien/brand-codex"
```

This repo's own `hugo.toml` declares where its files mount, so consumers only need the import.
